# Portfolio d'Oussama

Portfolio personnel orienté cybersécurité : projets réseaux, pare-feu, test d'intrusion et développement web.

Site statique en un seul fichier (`index.html`), sans dépendance à installer.

## Voir le site en local

Ouvre `index.html` dans ton navigateur.

## Mettre en ligne avec GitHub Pages

1. Dans les paramètres du dépôt, ouvre **Pages**.
2. Source : **Deploy from a branch**, branche `main`, dossier `/ (root)`.
3. Le site sera disponible à l'adresse `https://oussamamadih23-coder.github.io/portfolio/`.

## Personnaliser

- Contact : décommente les lignes e-mail et LinkedIn dans la section `#contact`.
- Projets : duplique un bloc `<article class="project ...">` (classes `net`, `off` ou `web` pour la couleur).
